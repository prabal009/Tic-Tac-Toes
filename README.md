# Tic Tac Toe 

A simple, minimalist Tic Tac Toe game built using HTML, CSS, and JavaScript. 

##  About This Project

This is my first JavaScript-based project! I built this with the help of **Apna College** web development course. 

I know this is an easy, simple game, and it is "no big deal" in the grand scheme of software engineering. However, for me, this marks a milestone. It is my first stepping stone towards the long goals.

##  What I Learned Along the Way

Building this simple game helped me solidify several core programming concepts. Here is a list of things I practiced and learned:

### JavaScript Fundamentals
*   **DOM Manipulation:** Selecting elements (buttons, containers) and dynamically updating their text content and styling based on game state.
*   **Event Listeners:** Handling user interactions by attaching click events to the grid boxes.
*   **Arrays:** Storing the game board state and using arrays to represent winning combinations.
*   **Loops:** Iterating through the grid to check for wins or draws.
*   **Conditional Logic:** Using `if-else` statements and Booleans to turn the game logic on/off and determine the winner.
*   **Functions:** Writing clean, modular functions to handle the game flow (e.g., `checkWinner`, `resetGame`, `newGame`).

### CSS & Responsive Design
*   **Flexbox:** Using CSS Flexbox to perfectly center the game board and align elements on the screen.
*   **Pseudo-classes:** Using `:hover` effects to make the buttons more interactive.
*   **Transitions:** Adding smooth visual transitions to enhance the user experience.
*   **Styling:** Creating a clean, modern, and user-friendly interface from scratch.


##  How to Play
1.  Clone the repository or download the files.
2.  Open `index.html` in your preferred web browser.
3.  Click on the boxes to take turns (Player X and Player O).
4.  The game will highlight the winner or declare a draw.
5.  Click the reset button to start a new round!
